# C++ Coding Standards

1. **Use camelCase for variable names:** All local variables must start with a lowercase letter and capitalize subsequent words (e.g., `double studentAverage = 0.0;`).
2. **Use 4 spaces for indentation:** Every block inside curly braces `{}` must be indented by 4 spaces.
3. **Use meaningful identifier names:** Avoid single-letter variable names except for standard loop counters like `i` (e.g., use `score` instead of `s`).
4. **One statement per line:** Never write multiple variable declarations or expressions on the same line (e.g., declare `int count = 0;` and `double sum = 0.0;` on separate lines).
5. **Comment major logic blocks:** Add concise single-line comments `//` explaining input validation, grade calculation, and summary output.
